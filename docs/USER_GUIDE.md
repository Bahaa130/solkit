## 1. مقدمة عن المنصة

### ما هي SOLKIT؟
SOLKIT هي منصة رقمية تدعم **كسب العملات الرقمية** عبر أنشطة يومية ممتعة. تستخدم تقنية سولانا (Solana) لإدارة العملات بشكل شفاف وآمن.

### كيف تعمل المنصة؟
```
1. تنشئ حساباً (ربط محفظة Phantom)
2. تكسب LOL (التوكن الرئيسي) عبر:
   - ⛏️ التعدين اليومي
   - ✅ إكمال المهام
   - 🎮 الألعاب المصغرة
   - 🎁 البونص اليومي
   - 🎰 عجلة الحظ
   - 📈 شراء البطاقات
3. تراكم رصيدك في حسابك
4. المدير يوزّع التوكنات الحقيقية على البلوكشين
5. تحول LOL إلى عملات حقيقية可以在 البرمجيات (Raydium/Orca)
```

### ما هو LOL؟
- **الرمز:** LOL
- **الشبكة:** سولانا (Solana)
- **العدد:** 1,000,000 توكن (عرض ثابت)
- **القيمة:** تتغير حسب العرض والطلب في البورصة
- **الاستخدام:** يمكنك استخدام LOL داخل المنصة أو بيعها في البورصة

## 3. Mining — التعدين اليومي

### ما هو التعدين؟
```
التعدين = توليد LOL بشكل مستمر (كل ثانية تقريباً) أثناء نشاطك

مثال:
- المستوى 1: 0.5 LOL/ساعة
- المستوى 5: 0.95 LOL/ساعة
- المستوى 9: 1.85 LOL/ساعة
```

### كيف تعمل التعدين؟
```
1. اضغط "بدء التعدين" → يبدأ العداد لمدة 24 ساعة
2. العداد ي-work في الخلفية (حتى لو أغلقت التطبيق)
3. بعد 24 ساعة: اجمع رصيدك (اضغط "جمع التعدين")
4. أعد التعدين فوراً للاستمرار في الكسب
```

### نصائح التعدين
```
✅ اجمع رصيدك كل 24 ساعة (لا يتجاوز 48 ساعة — يتوقف)
✅ راقب مستوى XP — كلما زاد مستوى XP، زاد معدل التعدين
✅ استخدم البطاقات لزيادة المعدل
❌ لا تترك التعدين لأكثر من 48 ساعة (يتوقف تلقائياً)
```

## 4. المهام اليومية

### ما هي المهام؟
```
مهام يومية تكسبك LOL إضافياً عند إكمالها. كل مهمة لها مكافأة مختلفة.

أنواع المهام:
- ✅ مهمة اليوم الواحدة (يومية)
- ✅ مهمة الأسبوع الواحدة (أسبوعية)
- ✅ مهمة الشهر الواحدة (شهرية)
```

### أمثلة على المهام
```
المهام اليومية:
- تسجيل الدخول: +10 XP + LOL
- إكمال التعدين: +30 XP
- لعب لعبة واحدة: +5 XP

المهام الأسبوعية:
- دعوة صديق واحد: +50 XP
- إكمال 7 أيام تعدين: +100 XP
```

### كيف تكمل المهام؟
```
1. اذهب إلى "المهام" في القائمة
2. اختر المهمة التي تريد إكمالها
3. اتبع التعليمات
4. بعد الإكمال: المكافأة تُضاف تلقائياً لحسابك
```

## 5. الألعاب المصغرة

### ما هي الألعاب؟
```
ألعاب بسيطة تكسبك LOL عند الفوز. بعضها يعتمد على الحظ وبعضها على المهارة.

أنواع الألعاب:
- 🎲 لعبة النرد (حظ)
- 🃏 لعبة الورق (مهارة)
- 🎯 لعبة الهدف (دقة)
- 🧩 لعبة الألغاز (ذكاء)
```

### كيف تلعب؟
```
1. اذهب إلى "الألعاب" في القائمة
2. اختر اللعبة
3. اضغط "ابدأ اللعب"
4. العب حسب قواعد اللعبة
5. عند الفوز: LOL يُضاف لحسابك
6. يمكنك العب بعدد محدود من المحاولات يومياً
```

### مكافآت الألعاب
```
المركز الأول: 5-10 LOL
المركز الثاني: 2-5 LOL
المركز الثالث: 1-2 LOL
مشاركة: 0.5 LOL
```

## 6. البونص اليومي

### ما هو البونص؟
```
مكافأة يومية تحصل عليها عند فتح التطبيق كل يوم. المكافأة تزداد كل يوم متتالي.

مثال:
- اليوم 1: 1 LOL
- اليوم 2: 2 LOL
- اليوم 3: 3 LOL
- اليوم 4: 4 LOL
- اليوم 5: 5 LOL
- اليوم 6: 6 LOL
- اليوم 7+: 10 LOL (الحد الأقصى)
```

### كيف تحصل على البونص؟
```
1. افتح التطبيق كل يوم
2. اذهب إلى "البونص" في القائمة
3. اضغط "جمع البونص"
4. المكافأة تُضاف فوراً لحسابك
```

### نصائح البونص
```
✅ افتح التطبيق كل يوم (لا تكسر السلسلة)
✅ اليوم السابع يعطيك أكبر مكافأة
❌ إذا نسيت يوماً: السلسلة تبدأ من جديد
❌ لا يمكنك جمع البونص أكثر من مرة في اليوم
```

## 7. البطاقات الاحترافية

### ما هي البطاقات؟
```
بطاقات تشتريها بـ LOL لزيادة دخلك اليومي. كل بطاقة لها ميزة مختلفة.

أنواع البطاقات:
- 🤳 مؤثرون للتسويق: +0.04 LOL/استخدام
- 🎬 فيديو ترويجي: +0.08 LOL/استخدام
- 🖼️ لافتات إعلانية: +0.16 LOL/استخدام
- 📣 قنوات تيليجرام: +0.32 LOL/استخدام
- 🎟️ كوبونات خصم: +0.64 LOL/استخدام
- 📺 إعلان تلفزيوني: +1.20 LOL/استخدام
```

### كيف تشتري البطاقات؟
```
1. اذهب إلى "البطاقات" في القائمة
2. اختر البطاقة التي تريد شراءها
3. اضغط "شراء البطاقة"
4. الموافقة على الدفع (من رصيد LOL في حسابك)
5. البطاقة تنشط فوراً
```

### كيف تعمل البطاقات؟
```
1. بعد الشراء: البطاقة تظهر في "بطاقاتي"
2. اضغط "استخدم" كل [المدة] (مثلاً كل 24 ساعة)
3. LOL يُضاف تلقائياً لحسابك
4. يمكنك ترقية البطاقة (تكلفة كل مرة تزداد بـ costGrowth)
5. الحد الأقصى للمستوى: 10-20 (حسب البطاقة)
```

### مثال على حساب التكلفة
```
بطاقة: مؤثرون للتسويق
- baseCost: 50 LOL
- costGrowth: 1.18 (18% زيادة كل مستوى)

- المستوى 1: 50 LOL
- المستوى 2: 50 × 1.18 = 59 LOL
- المستوى 3: 59 × 1.18 = 69.62 LOL
- المستوى 10: 50 × (1.18)⁹ = 221.97 LOL

المكافأة: 0.04 LOL كل استخدام
```

## 13. الأسئلة الشائعة

### س: لماذا لا أرى رصيد LOL في محفظتي على Phantom؟
```
ج: LOL存在于 في حسابك على المنصة (ليس في Phantom مباشرة)
    للتحويل: اذهب إلى "السحب" → أكمل الخطوات
    التوكنات الحقيقية تظهر في Phantom فقط بعد السحب
```

### س: لماذا يظهر لي "غير مربوط" بعد ربط المحفظة؟
```
ج: هذا يعني أنك لم تدفع رسوم التنشيط (0.03 SOL)
    اذهب إلى "التنشيط" → ادفع 0.03 SOL → يُفعّل حسابك فوراً
```

### س: لماذا يتوقف التعدين أحياناً؟
```
ج: التعدين يتوقف إذا:
    1. لم تجمع الرصيد لأكثر من 48 ساعة
    2. انتهى المدة (24 ساعة) ولم تُعد التعدين
    الحل: اجمع رصيدك وأعد التعدين فوراً
```

### س: كيف أعرف إذا كان صديقي انضم عبر رابطي؟
```
ج: اذهب إلى "الإحالات" → سترى قائمة الأصدخاص المنضمين
    كل صديق يظهر مع: تاريخ الانضمام + مكافأتك
```

### س: لماذا لا أستطيع لعب الألعاب؟
```
ج: تحقق من:
    1. هل حسابك مُنشّط؟ (يجب أن يكون "نعم")
    2. هل استنفدت محاولاتك اليومية؟
    3. هل انت意大ت الألعاب المتاحة اليوم؟
```

### س: كيف أcalculate أرباحي اليومية؟
```
ج: أرباحك اليومية = التعدين + البونص + المهام + البطاقات

مثال:
- التعدين: 12 ساعة × 0.5 LOL/ساعة = 6 LOL
- البونص: 5 LOL
- المهام: 2 LOL
- البطاقات: 0.5 LOL
- الإجمالي: 13.5 LOL يومياً
```

### س: هل LOL لها قيمة حقيقية؟
```
ج: نعم!
    1. LOL = توكن سولانا حقيقي
    2. يمكنك بيعه في: Raydium, Orca, Jupiter
    3. يمكنك تحويله لـ: USDC, USDT, SOL
    4. القيمة تتغير حسب العرض والطلب
    5. колебается من 0.001$ إلى 0.1$ حسب مرحلة المشروع
```

### س: كيف أحمي حسابي؟
```
ج: نصائح أمنية:
    1. لا تشارك مفتاح المحفظة مع أي شخص
    2. لا تضغط على روابط مشبوهة
    3. تحقق من العناوين دائماً قبل التحويل
    4. استخدم كلمة مرور قوية للمحفظة
    5. فعّل المصادقة الثنائية (2FA) على Phantom
```

## 14. نصائح للربح الأقصى

### الاستراتيجية المثلى
```
1. كل يوم:
   - اجمع البونص (+10 LOL max)
   - دوّر العجلة (50 دورة مجانية)
   - أكمل المهام اليومية (+2-5 LOL)
   - اجمع التعدين (+0.5-1.85 LOL/ساعة)

2. كل أسبوع:
   - شارك رابط إحالتك (_hashes و XPs إضافية)
   - ترقية البطاقات (إذا كان عندك LOL كافي)
   - العب الألعاب (حاول الفوز)

3. كل شهر:
   - راقب مستوى XP (هل ارتفع؟)
   - قارن أرباحك (هل تحسن؟)
   - شارك تجربتك مع الأصدقاء
```

### حساب الأرباح الشهرية
```
أرباح يومية متوسطة: 10 LOL
أرباح شهرية: 300 LOL

إذا كان سعر LOL = 0.01$:
→ 300 × 0.01 = 3$ شهرياً

إذا كان سعر LOL = 0.1$:
→ 300 × 0.1 = 30$ شهرياً

إذا كان سعر LOL = 1$:
→ 300 × 1 = 300$ شهرياً
```
