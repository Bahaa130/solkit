## 1. نظرة عامة على المنصة

### ما هي SOLKIT؟
منصة رقمية تدعم **كسب العملات** عبر:
- ⛏️ التعدين اليومي (Mining)
- ✅ إكمال المهام (Tasks)
- 🎮 الألعاب المصغرة (Games)
- 🎁 البونص اليومي (Daily Bonus)
- 🌐 شبكة الإحالات (Referral Network)
- 🎰 عجلة الحظ (Wheel of Fortune)
- 📈 البطاقات الاحترافية (Upgrade Cards)

### نموذج العمل (Business Model)
```
المستخدمون يكسبون → يراكمون رصيداً داخلياً → المدير يوزّع توكنات حقيقية على البلوكشين
↓
المنصة تجذب المستخدمين → يشترون التنشيط والبطاقات ( SOL ) → دخل مباشر للمدير
↓
التوكنات الموزعة تُتداول في البورصة → رسوم نقل تلقائية → دخل سلبي للمدير
↓
الإحالات والتسويق → نمو المستخدمين → نمو القيمة
```

## 3. إعداد التوكن وإطلاقه

### المقدمة
التوكن هو العملة الرقمية الخاصة بالمنصة. المستخدمون يكسبون رصيداً داخلياً ثم يحصلون على توكنات حقيقية على سولانا.

### خطوات الإطلاق

#### الخطوة 1: اختيار الشبكة
```
DevNet  → للتجربة (مجاني — يأخذ SOL من الـ Faucet)
MainNet → للإطلاق الحقيقي (يحتاج SOL حقيقي من منصة/)
```

**ملاحظة:** أثناء التطوير استخدم DevNet. عند الإطلاق انتقل إلى MainNet.

#### الخطوة 2: تحديد المحفظة
```
المحفظة الرئيسية (ADMIN_WALLET): 4NC1c6ZUrpTibV1FuxomBstGbkjXWNYtJwYvbFezKuQo
- هذه المحفظة تحصل على جميع أرباح التنشيط
- هذه المحفظة تُوزّع التوكنات على المستخدمين
- هذه المحفظة تتلقى أرباح رسوم النقل
```

**⚠️ تحذير أمني:** لا تشارك مفتاح المحفظة السري أبداً! احفظه في مكان آمن.

#### الخطوة 3: إنشاء التوكن
```
جاهز: نستخدم سكربت setup-token.ts
```

**أثناء التطوير (DevNet):**
```bash
cd backend
npx tsx scripts/setup-token.ts
```
- سينشئ توكن بالاسم المحدد في .env
- سينشئ حساب خزانة (ATA) للمحفظة الرئيسية
- سيصك العرض الكامل في الخزانة
- سيحول سلطة الصك للمدير

**عند الإطلاق (MainNet):**
```bash
# 1. وجه .env
SOLANA_NETWORK=mainnet
SOLANA_RPC_URL=https://mainnet.helius-rpc.com/?api-key=YOUR_KEY

# 2. وجه المحفظة بدلاً من المفتاح المؤقت
npx tsx scripts/setup-token.ts --keypair /path/to/your-secret-key.json
```

#### الخطوة 4: ضبط الإعدادات
```
في settings.json على الخادم:
{
  "tokenMint": "5Xxxxxx...xXx",  // mint of the token created
  "tokenDecimals": 9,             // 9 is standard for Solana tokens
  "solanaNetwork": "mainnet",     // devnet for testing, mainnet for launch
  "treasuryWallet": "4NC1c6ZUr...",  // your main admin wallet
  "tokenSymbol": "LOL",           // your token symbol
  "tokenName": "LOL Token"        // full name
}
```

#### الخطوة 5: الإعدادات المهمة في الـ .env
```
ADMIN_WALLET=4NC1c6ZUrpTibV1FuxomBstGbkjXWNYtJwYvbFezKuQo
SOLANA_RPC_URL=https://mainnet.helius-rpc.com/?api-key=YOUR_KEY
SOLANA_NETWORK=mainnet
DATABASE_URL=postgresql://...    // قاعدة بيانات Render
```

## 4. إدارة المستخدمين

### ملخص حساب المستخدم
```
┌─────────────────────────────────────────────────────┐
│  حساب المستخدم:                                      │
│  ├── العنوان: 0x... (88 حرف base58)                 │
│  ├── المستوى: 1-9 (التقدم يعتمد على XP)             │
│  ├── الرصيد: LOL (التوكنات المكتسبة)                │
│  ├── الخبرة: XP (نقاط الإنجاز)                      │
│  ├── حالة التنشيط: (نعم/لا)                          │
│  ├── تاريخ الانضمام: UTC                            │
│  └── إعادة التعيين: (نعم/لا)                         │
└─────────────────────────────────────────────────────┘
```

### مراقبة المستخدمين
```
-افة متجر: بحث بالعنوان (المحفظة) أو المستوى
- اضغط على المستخدم لرؤية التفاصيل
- يمكنك تعديل الرصيد والمستوى يدوياً (للدعم الفني)
```

### العناصر الرئيسية
| العنصر | الوصف | ملاحظات |
|--------|-------|---------|
| **العنوان** | محفظة المستخدم على سولانا | فريد لكل مستخدم |
| **المستوى** | 1-9 (المبتدئ → الأسطوري) | يعتمد على XP |
| **الرصيد** | التوكنات المكتسبة | يتحدث من الخادم |
| **حالة التنشيط** | مربوط / غير مربوط | ي depended on activation |
| **تاريخ الانضمام** | افتتح الحساب | يحفظ في قاعدة البيانات |

## 5. توزيع الجوائز

### نموذج التوزيع
```
المستخدمون يكسبون رصيداً داخلياً → المدير يضغط "توزيع المجمع وتصفير الأرصدة"
↓
1. حساب حصص كل مستخدم (الرصيد ÷ إجمالي المجمع)
2. بناء معاملات سولانا (TransferChecked)
3. توقيع المعاملات عبر محفظة المدير (Phantom)
4. تأكيد المعاملات على البلوكشين
5. تسجيل التوزيع في الخادم
6. تصفير الأرصدة internally
```

### آلية التوزيع خطوة بخطوة

#### الخطوة 1: تجهيز المعاينة
```
1. ادخل لوحة التحكم → التوزيع
2. اضبط النسبة (100% أو أقل)
3. اضغط "تجهيز توزيع رصيد المجمع"
→ يعرض جدول المستلمين: العنوان، المستوى، الرصيد، الحصة، سيستلم، حالة الحساب
```

#### الخطوة 2: مراجعة الجدول
```
تأكد من:
- عدد المستلمين (يجب أن يكون إجماليهم ≥ 0)
- الحصص متساوية ومحددة
- لا يوجد حسابات "غير صالح/تجريبي"
- إجمالي التوزيع = رصيد المجمع المتراكم
```

#### الخطوة 3: التنفيذ
```
1. اضغط "توزيع المجمع وتصفير الأرصدة"
2. سيفتح تطبيق Phantom للمدير للتوقيع
3. وافق على كل معاملة ( batching )
4. بعد كل دفعة: يتحقق من تأكيد البلوكشين
5. يسجّل النتيجة في الخادم

⚠️ ملاحظة: التطبيق على الهاتف يعرض "تأكيد الدفع" مباشرة
(لا تظهر شاشة "ربط المحفظة" — الجلسة محفوظة محلياً)
```

#### الخطوة 4: التحقق
```
- افتح سجل الدفعات في لوحة التحكم
- تحقق من التوقيعات على Solscan
- تأكد من وصول التوكنات للمستخدمين
```

### نسب التوزيع
```
إجمالي المجمع = مجموع أرصدة المستخدمين (LOL)

مثال:
- المستخدم A: رصيد 100 → حصته 20% (إجمالي 500)
- المستخدم B: رصيد 150 → حصته 30%
- المستخدم C: رصيد 250 → حصته 50%

إذا وضعت 100 توكن، سيستلم:
- A: 20 توكن
- B: 30 توكن
- C: 50 توكن
→ ثم تُصفّر الأرصدة (المستوى والخبرة يبقى)
```

### جدولة التوزيعات
```
التوزيع يدوي:
- شهري: ممتاز للمرحلة الأولى
- نصف شهري: عند وصول 1000+ مستخدم
- أسبوعي: عند الاستقرار (10,000+ مستخدم نشط)

ملاحظة: التكرار يرفع الطلب على التوكن ويزيد رسوم النقل
```

## 6. إعداد العجلة والبطاقات

### عجلة الحظ
```
segments:
- 0.5 LOL (وزن 22) — الأعلى تكراراً
- 1.0 LOL (وزن 20)
- 1.5 LOL (وزن 18)
- 2.0 LOL (وزن 14)
- 2.5 LOL (وزن 10)
- 3.0 LOL (وزن 8)
- 5.0 LOL (وزن 5) — نادر
- 12.0 LOL (وزن 3) — نادر جداً

الإجمالي: ~4.5 LOL لكل 100 دورة
الحد اليومي: 50 دورة
المبرد: 3600 ثانية (ساعة)
```

### البطاقات
```
كل بطاقة تمثل "ميزة" تشتريها بـ LOL:
- 🤳 مؤثرون للتسويق: كل 24 ساعة
- 🎬 فيديو ترويجي: كل 24 ساعة
- 🖼️ لافتات إعلانية: كل 48 ساعة
- 📣 قنوات تيليجرام: كل 48 ساعة
- 🎟️ كوبونات خصم: كل 72 ساعة
- 📺 إعلان تلفزيوني: كل 96 ساعة
```

### إنشاء بطاقة جديدة
```
1. اضغط "إضافة بطاقة"
2. أدخل: المفتاح (key)، الأيقونة، اللون
3. ضبط التكلفة والمكافأة:
   - baseCost: التكلفة الأساسية (بـ LOL)
   - costGrowth: معدل النمو (كل مرة تشريها = التكلفة × costGrowth)
   - reward: المكافأة لكل استخدام (بـ LOL)
   - maxLevel: الحد الأقصى لمستوى البطاقة
   - duration: مدة التأثير (بأيام)
```

### مثال على حساب تكلفة البطاقة
```
بطاقة: مؤثرون للتسويق
- baseCost: 50 LOL
- costGrowth: 1.18
- Level 1: 50
- Level 2: 50 × 1.18 = 59
- Level 3: 50 × (1.18)² = 69.62
- Level 10: 50 × (1.18)⁹ = 221.97
```

## 7. تسيير الضرائب والرسوم

### رسوم التنشيط
```
المستخدم يدفع 0.03 SOL لتفعيل حسابه
→ SOL يذهب مباشرة لمحفظة المدير (ADMIN_WALLET)
→ التنشيط يفتح جميع ميزات المنصة للمستخدم
→ بدون تنشيط: التعدين وطيء جداً (×0.5) ولا يمكنه بناء البطاقات
```

### رسوم النقل (Token-2022)
```
إذا أنشأت التوكن بـ Token-2022:
- كل تحويل يأخذ 1-2% تلقائياً
- النسبة تذهب لـ feeRecipient (محفظة المدير)
- المستخدمون لا يشعرون بالفرق (الرسوم منخفضة)
- أنت تحصل على دخل سلبي مع كل تحويل
```

### حسابات نموذجية
```
إذا كان لديك 1000 مستخدم نشط، وكلهم يكتبون 0.03 SOL:
→ 30 SOL شهرياً من التنشيط فقط

إذا كان هناك 10,000 تحويل للتوكن شهرياً بمتوسط 100 LOL:
→ 10,000 × 100 × 1% = 100,000 LOL شهرياً لمحفظتك
```

## 8. إطلاق الاكتتاب (ICO/IEO)

### إذا أردت إجراء اكتتاب رسمي

```
1. توكن جاهز على MainNet
2. بورصة سائلة على Raydium/Orca
3. صفحة ويب احترافية (landing page)

```

#### نموذج حساب الاكتتاب
```
إجمالي العرض: 1,000,000 LOL
- حصة الاكتتاب: 40% (400,000 LOL)
- حصة الفريق: 15% (150,000 LOL) — مقفلة 12 شهر
- حصة السيولة: 20% (200,000 LOL) — في البورصة
- حصة التعدين: 25% (250,000 LOL) — للzeitraum

سعر الاكتتاب: 0.01 SOL لكل LOL
الحد الأدنى: 0.1 SOL (10 LOL)
الحد الأقصى: 10 SOL (1,000 LOL)
```

#### جدول التوزيع (Vesting)
```
المستثمر يحصل على:
- 25% عند الاكتتاب (فوراً)
- 25% بعد 3 أشهر
- 25% بعد 6 أشهر
- 25% بعد 12 شهر

الفريق يحصل على:
- 0% لمدة 12 شهر (مقفل)
- ثم 25% كل 3 أشهر لمدة 12 شهر
```

## 11. نصائح ذهبية

### ✅ افعل
```
- ابدأ صغيراً (DevNet أولاً)
- اختبر كل شيء قبل الإطلاق
- حافظ على التوزيعات منتظمة (even if small)
- أنشئ مجتمعاً (Discord/Telegram)
- استمر في التحديثات (مستخدم جديد كل أسبوع)
```

### ❌ لا تفعل
```
- لا تكثر من الصك (ندرة = قيمة)
- لا تتوقف عن التوزيع (users need trust)
- لا تشارك مفاتيحك السرية
- لا تراقب المستخدمين بالغش (lost trust = lost platform)
```
